# AI-Generated Content Detection Using Deep Learning

## 📌 Overview

AI-Generated Content Detection is a deep learning-based web application that identifies whether digital content has been created by Artificial Intelligence or by humans.

The project initially focuses on AI-generated image detection based on recent research and extends the system to detect AI-generated text. Future versions will also support AI-generated video and voice detection.

---

## 🎯 Objectives

- Detect AI-generated images.
- Detect AI-generated text.
- Display prediction confidence.
- Provide a clean and user-friendly interface.
- Build a scalable system that supports future multimedia detection.
